# CSE103 Lab — LAB 3: GitHub Collaboration & API Interaction


## Overview

This repository contains my work for **CSE103 – Computer Fundamentals & Career Pathways** at **K.R. Mangalam University, Gurugram**.

The objective of this lab is to understand Git and GitHub collaboration, version control, Markdown documentation, and API interaction.

## How to Run

Clone the repository:

```bash
git clone https://github.com/JustALivingCreature/cse103-lab-LAB3.git
```

Navigate into the project:


```bash
cd cse103-lab-LAB3
```

Run the Python program:

```bash
python3 main.py
```

## Learning Outcomes

- Understanding version control using Git.
- Creating and managing repositories on GitHub.
- Tracking changes through meaningful commits.
- Synchronizing local and remote repositories.
- Writing structured documentation using Markdown.
- Understanding the basics of API interaction.
